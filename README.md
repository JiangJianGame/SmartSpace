# SmartSpace (智慧空间)

基于 **Unity 2019.4 LTS (客户端)** 与 **Colyseus (网络后端)** 打造的开放式云端浮空智慧空间。

玩家登录后进入宏大的云端浮岛大空间，可以在高科技与自然生态融合的场景中自由漫游探索，与场景中的科幻装置进行深度交互，并在特定交互锚点触发多人小游戏匹配对战、创建/加入定制化云端小课堂等业务。

---

## 🌌 大空间场景规划 (The Grand Space)

### 1. 世界观与视觉基调
* **风格定位**：明亮生态科幻·云端浮空智慧城（Solarpunk / Sci-Fi Eco-City）。
* **视觉构成**：碧空云海背景、远景神秘天体环绕、蜂巢模块化浮空岛屿群、地面贯穿全岛的蔚蓝能量光轨网络。

### 2. 核心地标与功能分区
| 区域名称 | 对应视觉形态 | 核心功能定位 |
| :--- | :--- | :--- |
| **中央智慧神树·星环广场** | 参天粉色能量光子巨树、环形广场 | 全场核心视觉地标，全岛玩家社交集散地、挂机交流、神树共鸣互动。 |
| **登岛空港迎宾站** | 白色流线型穿梭机停机坪、起降跑道 | 玩家初次登录出生点，配备全岛信息导览台与形象换装舱。 |
| **生态光幕穹顶** | 巨型半透明玻璃生态球体 | **云端课堂/讲座研讨区**。平时通透开放，开课时可升起降噪光幕与全息黑板。 |
| **VS 浮空竞技飞艇** | 悬浮流线型飞艇，醒目“VS”霓虹标识 | **小游戏/派对娱乐区**。设有对战擂台与观战大屏。 |
| **翡翠花瓣展台** | 绿色多边形莲花状开放台座 | 休闲观景平台、3D数字孪生模型展台、多人合影打卡点。 |
| **全岛能量光轨步道** | 穿梭连接各岛屿的悬浮蓝光桥廊 | 具备加速机制的光轨步道，支持高速滑行与穿环竞速探索。 |

## 🎮 交互机制与核心玩法规划

本项目采用**类似《奥拉星》手游的“场景实体装置触发 + UI 面板业务流”**交互模型，所有功能均以大空间里的具体科幻装置为入口：

```
[玩家在大空间漫游] ──(靠近特定装置按 E)──> [弹出专属 UI 交互面板] ──> [完成配置/匹配] ──> [进入具体流程]
```

### 1. 云端课堂系统 (Classroom System)
* **交互载体**：【智慧晶核中控台】（设立于生态穹顶等研讨区域）。
* **UI 交互全流程**：
  * **开课流程 (Host)**：
    * 玩家走近中控台按 `E`，打开《智慧课堂中心》面板，点击【创建新课堂】；
    * 弹出设置窗口：配置**课堂主题**、**最大容纳人数**（如 10人 / 20人 / 50人）、**准入权限**（公开免费进 / 勾选设密并输入 4~6 位数字密码）；
    * 确认开课后，服务端分配课堂房间，讲师进入授课主持模式。
  * **听课/加入流程 (Student)**：
    * 其他玩家走近中控台，面板主视图展示**实时课堂列表**（展示课堂名称、讲师、在线人数、是否带锁 🔒）；
    * 若为公开且未满员课堂，点击直接进入；
    * 若带锁，点击弹出密码输入框，验证通过后进入；满员则提示无法加入。

### 2. 休闲小游戏对决 (Mini-Game System)
* **交互载体**：【全息对战战桩 / 竞技终端】（设立于 VS 飞艇等区域）。
* **UI 交互全流程**：
  * 玩家走近终端按 `E` 唤起《对决匹配大厅》；
  * 查看当前游戏规则、历史战绩与排队情况；
  * 支持【快速随机匹配】或【创建专属好友房间】；
  * 匹配就绪后直接启动轻量对战，结算积分后无缝返回大空间。

### 3. 可扩展性设计 (Pluggable Slots)
* 场景中的交互装置作为**通用功能插槽**，其物理外观与挂载的业务完全解耦；
* 大空间场景基础落成后，后续可通过配置或热更新灵活切换任意点位绑定的具体游戏或活动内容。

## 🛠️ 技术栈与依赖

* **Unity Editor**：`2019.4.36f1c1` (C# 7.3)
* **渲染管线**：Universal Render Pipeline (URP) / Built-in + Post Processing
* **实时网络后端**：Colyseus (Node.js / TypeScript)
* **AI 编辑器控制协议**：[UnityMCP](https://github.com/JiangJianGame/UnityMCP) (基于 MCP 协议的 2019.4 兼容分支)
